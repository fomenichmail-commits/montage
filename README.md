# Montage

Веб-приложение для монтажа видео. Работает в браузере, видео собирается на вашем компьютере через FFmpeg.

## Возможности

- **Медиатека**: загрузка видео, фото и музыки (кнопкой или перетаскиванием), превью-картинки.
- **Таймлайн**: клипы ставятся по порядку, переставляются перетаскиванием, масштаб регулируется.
- **Обрезка**: начало и конец клипа задаются числами или по текущему кадру в плеере.
- **Разрезание** клипа по текущему кадру, дублирование, удаление.
- **Фото на таймлайне** с выбранной длительностью.
- **Титры** поверх кадра: снизу, по центру или сверху.
- **Плавное появление и исчезание** (fade in / fade out) картинки и звука.
- **Громкость** каждого клипа, отключение звука.
- **Фоновая музыка** на отдельной дорожке: зацикливается, затухает в конце, громкость настраивается.
- **Предпросмотр** всего проекта прямо в браузере.
- **Экспорт в MP4** (H.264 + AAC) с индикатором прогресса:
  - 16:9 — 480p / 720p / 1080p;
  - 9:16 — Reels, Shorts, Stories;
  - 1:1 — квадрат;
  - 24 / 25 / 30 / 60 кадров в секунду.
- **Автосохранение проекта**: после перезапуска всё на месте.

## Установка

Нужны [Node.js](https://nodejs.org/) 18+ и [FFmpeg](https://ffmpeg.org/download.html) (команды `ffmpeg` и `ffprobe` должны быть в `PATH`).

```bash
# macOS
brew install node ffmpeg
# Ubuntu / Debian
sudo apt install nodejs npm ffmpeg
# Windows
winget install OpenJS.NodeJS FFmpeg
```

```bash
git clone https://github.com/fomenichmail-commits/montage.git
cd montage
npm install
npm start
```

Откройте в браузере http://localhost:3000.

## Как монтировать

1. Нажмите **«+ Добавить»** или перетащите файлы в медиатеку.
2. Нажмите **«+»** у файла или перетащите его на таймлайн. Если добавить аудио, оно станет фоновой музыкой.
3. Выберите клип на таймлайне. Справа задайте обрезку, титр, переходы и громкость.
4. **Пробел** запускает и останавливает воспроизведение проекта, **Delete** удаляет выбранный клип.
5. Нажмите **«Экспорт MP4»**, выберите формат и нажмите **«Собрать видео»**, затем **«Скачать MP4»**.

## Remotion: видео из кода

В папке [`remotion/`](remotion/) лежит проект [Remotion](https://www.remotion.dev): заставки и анимации пишутся на React и рендерятся в MP4.
В репозитории также установлены официальные скиллы Remotion для Claude Code (`.claude/skills/`).
Команды `/remotion-create`, `/remotion-markup`, `/remotion-render` работают сразу, как только вы откроете этот репозиторий в Claude Code.
Подробности — в [remotion/README.md](remotion/README.md).

## SportCardsSPB: оформление YouTube-канала

Всё для канала о футбольных карточках Panini и Topps в стиле «Светлый премиум».

| Папка | Что внутри |
|---|---|
| [`brandbook/`](brandbook/index.html) | Брендбук монтажа: цвета, шрифты, плашки, бейджи, субтитры, звук, экспорт, чек-лист |
| [`channel/`](channel/README.md) | Шапка канала 2560×1440, аватар 800×800, описание и ключевые слова канала |
| [`youtube/`](youtube/) | Пакеты для загрузки: название, описание с главами, теги, английские субтитры `.srt`, тексты для Shorts |
| [`remotion/src/sportcards/`](remotion/README.md) | Заставки, плашки, бейджи, полный эпизод (`FullLight`) и вертикальные Shorts (`Short`) |

### Как собирается эпизод

1. Расшифровка речи (faster-whisper) с таймкодами по словам.
2. `build_edit.py` убирает паузы длиннее 0,6 с, дубли и оговорки, правит имена и цифры в субтитрах. Результат: укороченный мастер и `props.json` с плашками и бейджами.
3. Композиция `FullLight` накладывает заставку, смену масштаба на склейках, субтитры, плашки игроков, бейджи редкости и концовку.
4. Звук сводится к −14 LUFS, файл для YouTube кодируется в H.264 с битрейтом до 4,3 Мбит/с.
5. Композиция `Short` нарезает из того же мастера вертикальные ролики 1080×1920.

Правила, по которым всё это работает, описаны в брендбуке.

## Устройство

```
server/index.js    HTTP API: медиатека, проект, задачи рендера
server/ffmpeg.js   ffprobe, превью, сборка filter_complex для FFmpeg
public/            интерфейс (HTML/CSS/JS без сборки)
test/              тесты: генерируют клипы через FFmpeg и проверяют рендер
remotion/          проект Remotion (видео из кода на React)
brandbook/         брендбук монтажа SportCardsSPB (HTML)
channel/           шапка, аватар и описание канала
youtube/           тексты, субтитры и Shorts для загрузки на YouTube
.claude/skills/    скиллы Remotion для Claude Code
data/              ваши файлы (не попадают в git)
```

Рендер устроен так: каждый клип обрезается (`trim`), масштабируется под формат с чёрными полями (`scale` + `pad`), получает переходы (`fade`) и титр (`drawtext`). Затем клипы склеиваются (`concat`), а музыка подмешивается (`amix`).
